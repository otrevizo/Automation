# workflows/

One write-up per use case, describing what it does and why — e.g. `random-number-generator.md`.

Exported n8n workflow JSON, when included, goes here too, named to match its write-up (e.g. `random-number-generator.json`). Export with credentials/secrets stripped — n8n workflow exports can include credential references, so double-check before committing. Whether to publish a given workflow's JSON is decided case by case; a write-up doesn't require the JSON to also be here.
